# UX/UI Tips

Reference collection with 85 concrete UX/UI tips, split into thematic files under `references/` so you can read only the part relevant to the current task.

## When to use this skill

- You're designing or reviewing a UI component (form, table, modal, toast, dropdown, etc.).
- You're doing a UX audit of an existing interface (even one generated by AI).
- You want to justify a design choice with an established principle (psychology, accessibility, perceived performance).
- You're writing frontend code and want to avoid common mistakes (layout shift, focus trap, contrast, RTL, etc.).

## How to use it

Don't read every file: pick the one (or ones) relevant to the task using the table below, then cite the section (e.g., "see §55 focus state") instead of rewriting the content from memory.
